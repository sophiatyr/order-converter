CSQ 客戶工作站 — Windows 單機版

1. 雙擊「啟動訂單系統.bat」，開啟 http://localhost:8888。
2. 在「訂單作業 → 訂單核對」匯入 PO，確認下單公司、款色、尺碼件數及客戶售價。
3. 工廠名稱、成本、中文規格及交易條件在下方展開。
4. 到「訂單作業 → 訂單文件輸出」匯出 P/I、工廠採購單、數量明細表與早見表。
5. 可下載 JSON 訂單備份，從「匯入 PO」還原；產品對照庫請另行匯出备份。
6. 系統在背景執行，關閉啟動視窗不會停止。使用完畢可雙擊「停止訂單系統.bat」。
7. 電腦重開機後，請再次雙擊「啟動訂單系統.bat」。只開瀏覽器網址不會啟動服務。

所有文件解析、OCR 及 Excel 產生皆在本機，不使用外部 API 或金鑰。
資料保存在目前的瀏覽器；請固定使用同一瀏覽器及 http://localhost:8888。
本機服務預設只監聽 127.0.0.1:8888。尚未提供公司 Server 共用資料庫與多人權限。

Node.js 22 或以上版本；日常啟動不需安裝 npm 套件。
PDF／圖片／Excel／CSV／表格文字，最多 40 MB、PDF 最多 50 頁。
基本 CSQ Vendor PO 已支援；特殊 Kit composition 或品牌格式需逐版驗證。
可以直接讀取 SK-KPI 本機保存的 CSQ 解析 JSON，不連線 SK-KPI API。

修改原始碼後執行 npm run build 更新介面；npm test 與 npm run lint 驗證。

參考成份：讀取 CSQ參考資料\訂單作業\工廠採購單 裡的 Excel 檔，依完整款號與 PO 對應。
資料夾更新後，雙擊「更新CSQ參考資料.bat」，再按「重新讀取參考成份」。
採購單找不到或無法確認成份時，保留客人原始 PO 說明。
四種文件都有預覽；數量明細每款一個工作表，早見表沿用 CSQ-早見表-2026 格式。
工廠採購單依工廠分成獨立 Excel，多工廠以 ZIP 下載。
來源版型更新後，雙擊「更新CSQ參考資料.bat」，再按「重新讀取參考成份」。
所有數量合計从顏色明細重新計算，保留原範本欄位、字型及列印設定。

六個主選單：訂單作業、訂單追蹤、出貨作業、開發管理、產品資料、數據管理。
訂單核對與文件輸出合併到「訂單作業」，多份 PO 可由作業訂單選單切換。
訂單進度／Bulk Status／面料測試沿用 PO 資料，修改後保存在本機。
出貨作業由 PO 建立批次：填實際尺碼數量、箱數、重量與材積後確認出貨。
同一批資料可匯出客戶＋工廠通知、Packing List + Weight、Invoice。
數據管理的業績只計已確認實際出貨；出貨草稿、預計交期不計入。
開發款會加入產品資料，可依品牌、季節及下單狀態篩選並維護備註。
「數據管理 → 資料來源與備份」可下載完整工作站備份、合併匯入與重新讀取參考資料。
完整備份不含產品對照庫，該庫請另外匯出。
這是單機初步架構，文件版型及更完整自動化可逐步優化。
